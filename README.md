# Эд ПВЗ — PWA starter

Готовый статический PWA-портал. Разместите содержимое папки в корне нового репозитория GitHub и включите Settings → Pages → Deploy from a branch → main / root. Через HTTPS сайт можно добавить на главный экран iPhone (Safari → Поделиться → На экран «Домой») и Android (Chrome → Установить).

Существующие приложения пока открываются по исходным адресам, без изменения кода, авторизации и сохранений. Не реализованы единая регистрация, единая синхронизация, объединение кода и перенос информационных материалов бота. Для полноценного офлайна нужно отдельно адаптировать каждый инструмент. Внешние ссылки требуют интернета.
