Мой аккаунт Эд ПВЗ

Сохранить и перенести локальные данные

Один аккаунт — одна роль. Для регистрации нужны только логин и пароль. Пункты привязываются по ID после подтверждения собственником. Сотрудник может работать с несколькими собственниками.

Вход и регистрация

Логин используется для входа. Запомните его: подтверждение почты не требуется.

Забыли пароль? Напишите @edholod в Telegram. Никому не сообщайте свой пароль. Для восстановления потребуется проверка права владения аккаунтом.
