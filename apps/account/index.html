Мой аккаунт

Единый вход по электронной почте. Telegram не требуется. Личные данные хранятся отдельно для каждого аккаунта.

После регистрации может потребоваться подтвердить адрес электронной почты.

Аккаунт подключён. Здесь можно сохранять и восстанавливать резервные копии данных «Эд ПВЗ».

Резервная копия

Загрузите JSON-файл из существующего приложения или выберите локальные данные для резервного копирования. Облачное сохранение не удаляет оригинал на устройстве.

Восстановление данных в приложении выполняется через его функцию импорта резервной копии. Автоматическое слияние разных устройств пока не включено, чтобы избежать потери данных.
