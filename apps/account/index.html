Мой аккаунт Эд ПВЗ

Один аккаунт — одна роль. Пункты привязываются по ID после подтверждения собственником. Менеджер может работать с несколькими собственниками.

Вход и регистрация

Логин отображается в системе. Для входа пока используется почта: так безопаснее восстанавливать доступ.

Если подтверждение почты включено, завершите его перед первым входом.
