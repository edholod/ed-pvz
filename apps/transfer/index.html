Сохранение и перенос данных

Перед переходом на edpvz.ru откройте эту страницу в привычном браузере на старом адресе и сохраните копию. На новом адресе откройте «Мой аккаунт → Перенос данных» и выберите этот файл.

Копируются локальные настройки, календарь, заметки и сохранения разделов. Пароли, токены входа и код блокировки не переносятся. Облачные данные остаются в вашем аккаунте — войдите с прежним логином.

1. Сохранить на этом устройстве

Файл может содержать ваши рабочие записи. Храните его у себя.

2. Восстановить из файла

Перед восстановлением будет показан состав копии. Уже существующие записи сохраняются, различающиеся записи пропускаются целиком.

    Файл ещё не выбран.

    Если данные отличаются, сохраните копии с обоих адресов. Не закрывайте другие разделы с несохранёнными изменениями. После восстановления заново откройте нужный раздел.
