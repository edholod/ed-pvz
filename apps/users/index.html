Поиск пользователей

Найди зарегистрированного пользователя Эд ПВЗ по логину. Для защиты личных данных доступны только логин и роль, без телефонов и паролей.

Для поиска войдите в свой аккаунт.

Приглашения и запросы

Подключение к ПВЗ произойдёт только после согласия второй стороны. Права сотрудника настраивает собственник.
