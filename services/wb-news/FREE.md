# Бесплатный режим без постоянного сервера

`.github/workflows/wb-news-scheduled.yml` запускает Chromium на стандартном GitHub-hosted Linux runner каждые 30 минут. Это ограниченная по времени задача получения и публикации данных приложения, а не постоянно работающий сервер. Для публичного репозитория стандартные hosted runners бесплатны в пределах действующих правил GitHub. Запуски могут задерживаться; после 60 дней без активности GitHub может отключить расписание.

## Первый вход

Бесплатный вспомогательный сервис `ed-pvz-wb-login` используется только для ручного входа и экспорта сессии. Он не нуждается в постоянном диске. Допустимо его штатное засыпание и удаление временного профиля: после экспорта сбор выполняется в GitHub Actions. Искусственное поддержание сервиса активным не используется.

1. Откройте адрес сервиса и войдите в панель с ADMIN_TOKEN из Environment в Render.
2. Откройте браузер WB, самостоятельно авторизуйтесь, вернитесь и нажмите «Вход завершён — проверить новости».
3. После успешного получения новостей нажмите «Скачать сессию для GitHub Secrets».
4. В GitHub `edholod/ed-pvz` откройте Settings → Secrets and variables → Actions → New repository secret. Имя: `WB_SESSION`. Значение: содержимое скачанного файла. Не отправляйте содержимое в чат и не загружайте файл в репозиторий.
5. Запустите `Collect My PVZ news for free` вручную кнопкой Run workflow либо дождитесь расписания. После подтверждения успешного сбора удалите локальный файл сессии.

Секрет экспортируется только по нажатию владельца в защищённой панели. Через подключённый GitHub-инструмент в этой среде нельзя создавать repository secrets, поэтому добавление секрета остаётся действием владельца. Уже имеющаяся сессия браузера ChatGPT не извлекается и не переносится.

## Хранение

- `WB_SESSION`: gzip/base64 storage state, защищённый механизмом GitHub Secrets, максимум 45 000 символов; это кодирование, а не самостоятельное шифрование. Не размещать открыто.
- `data/wb-session.enc`: обновлённая сессия в AES-256-GCM. Ключ выводится из исходного секрета WB_SESSION. В открытом репозитории находится только шифротекст; ключ и исходное состояние не коммитятся.
- `data/wb-news.json`: разрешённые владельцем к публичному распространению новости и диагностический статус без данных аккаунта.
- `data/wb-news-config.json`: переключает приложение на GitHub Actions. Чтение свежего файла идёт напрямую, независимо от пересборки Pages.

При истечении входа или проверке WB сохраняются последние новости; повторные автоматические попытки приостанавливаются до изменения секрета. Владелец повторяет вход и заменяет WB_SESSION. Работоспособность переноса сессии между хостами зависит от WB и подтверждается только реальным запуском после авторизации. При привязке сессии к устройству бесплатный перенос может не работать; обходы проверок WB не используются.

Существующий платный вариант `render-wb-news.yaml` сохранён как необязательная альтернатива и автоматически не применяется.
