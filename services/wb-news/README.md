# Облачный сборщик «Мой ПВЗ»

Отдельный постоянный браузер получает последние карточки `/news/owners` и `/news/employees` каждые 15 минут. Никаких кликов по публикациям, кнопкам прочтения, реакциям или настройкам кабинета. Сборщик читает только DOM карточек; заголовок аккаунта, cookies и содержимое хранилищ не экспортируются.

## Запуск

`render-wb-news.yaml` в корне репозитория создаёт Docker web service с постоянным диском. Применение плана требует подтверждения владельца Render и платного тарифа. Секрет `ADMIN_TOKEN` генерирует Render. Сервис не зависит от работающего компьютера владельца.

После развёртывания откройте HTTPS-адрес сервиса. Возьмите ADMIN_TOKEN на странице Environment сервиса Render и введите только в панели сервиса. Нажмите «Открыть вход в WB», затем «Перейти в браузер WB». Самостоятельно войдите в WB. Вернитесь в панель и нажмите «Вход завершён — запустить сбор». Пароли и одноразовые коды не передаются в чат или GitHub.

Установите точный HTTPS-адрес созданного сервиса в `data/wb-news-config.json` (`endpoint`) и `enabled: true`. Клиентское приложение объединит `/api/news` с существующей публичной лентой. Никакие ключи на клиент не передаются. До настройки endpoint интерфейс честно сообщает, что источник не подключён.

## Хранение и ограничения

- `/var/lib/ed-pvz/browser`: профиль браузера с авторизованной сессией, только на постоянном диске сервера.
- `/var/lib/ed-pvz/feed.json`: атомарно обновляемый кэш до 500 новостей; прежние записи остаются при сбоях.
- `/api/news`: общая лента, доступная только при `PUBLISH_APPROVED=true`. Этот режим предназначен для подтверждённого владельцем разрешения на распространение новостей. Не включать при отсутствии такого разрешения.
- `/api/status`: технический статус без данных кабинета. `/healthz`: жизнеспособность HTTP-сервера, а не признак успешной авторизации WB.
- `/admin/*` и `/vnc/*`: управление защищено ключом, HttpOnly Secure cookie, проверкой Origin и ограничением попыток входа. Порты VNC и noVNC доступны только через localhost; наружу выставлен один HTTP-порт за HTTPS Render. Сеанс VNC закрывается через 15 минут, при завершении входа и при выходе из панели.
- Требование к хостингу: TLS, единственный экземпляр, постоянный диск, контейнер с Chromium/Xvfb. При переносе диска проверять владельца каталога pwuser (UID 1000).
- Сессия может истечь; потребуется ручной повторный вход. CAPTCHA и блокировки WB не обходятся; при обнаружении проверки сбор останавливается.
- Считываются последние загруженные карточки. Импорт всего архива и прокрутка для загрузки старых новостей не реализованы.
- Контейнер не предоставляет браузерный debug-порт или удалённый Playwright endpoint.

## Проверки

`npm test` — тесты нормализации, объединения, сохранения, деградации источников, администраторского доступа и запрета доступа к браузеру без входа. Реальный вход WB и полная Docker-сборка проверяются после запуска в Render. Не включать реальную сессию WB, кэш закрытых новостей, скриншоты входа или секреты в коммиты и архивы.
